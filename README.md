# 🥁 TuneBot - React 기반 안드로이드 드럼 튜닝 & 스펙트로미터 앱

Tune-Bot 공식 튜닝 가이드(Overtone Labs)의 수학적 공명 비율 및 화음 추천 데이터를 기반으로 제작된 React 기반 안드로이드 네이티브 드럼 튜너 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **드럼 모양 홈 화면 튜너 (`front.png` & `배치.png` 기반)**
   - **n기통 자유 설정**: 3기통, 4기통, 5기통, 6기통 지원
   - **실시간 피치 & 오차 미터**: 감지 주파수(Hz), 음정(Note), 튜닝 방향 화살표(▲/▼), 정음 녹색 표시
   - **고조파 & 오버톤 표시**: 옥타브 아래 기저음 / 5도 화음 / 상위 오버톤 주파수 실시간 모니터링
   - **윗면(Batter) & 아랫면(Resonant) 듀얼 타겟**:
     - 중앙(Fundamental, 기본음) 타겟 주파수
     - 러그(Lug) 타겟 주파수 (터치로 전환 및 필터 락)
   - **인터랙티브 드럼 킷**:
     - 1회 터치: 해당 드럼 선택 및 튜닝 모드 진입 (이중 링 하이라이트)
     - 2회 터치: 인치수(8"~22") 및 개별 공명(Max/High/Mid/Low) 세부 설정 모달

2. **스펙트로미터 워터폴 뷰 (`specto.png` 기반)**
   - **실시간 60fps 오디오 스펙트로그램**: 타격 시 나타나는 주파수 궤적을 네온 컬러 워터폴로 렌더링
   - **반음계(Chromatic) 가이드 와이어**: C부터 B까지 모든 반음 표시
   - **상단 피치 센트 슬라이더**: 목표 음정 대비 정밀 오차 바늘 표시
   - 옥타브 대역 선택 및 마이크 감도(Gain) 조절 지원

3. **튜닝가이드 화음 & 글로벌 공명 설정**
   - **화음 프리셋**: Major Thirds(장3도), Perfect Fourths(완전4도), Perfect Fifths(완전5도), Major Chord(메이저 코드), The Call to the Post
   - **글로벌 공명 공식**:
     - Maximum Resonance (상/하 러그 동일, 1.75x)
     - High Resonance (Top 1.5x / Bottom 1.85x)
     - Medium Resonance (Top 1.4x / Bottom 2.0x - 표준 추천)
     - Low Resonance (Top 1.2x / Bottom 2.3x)
   - 원클릭 일괄 적용 기능

## 📱 안드로이드 스마트폰 연결 및 실행 방법

### 1단계: 스마트폰에서 [개발자 옵션] 켜기
1. 스마트폰의 **[설정]** 앱 실행
2. 맨 아래 **[휴대전화 정보]** > **[소프트웨어 정보]** 이동
3. **[빌드번호]** 항목을 **연속으로 7번 빠르게 터치**
4. 화면에 *"개발자 모드를 켰습니다"* 라는 토스트 메시지가 뜸

### 2단계: [USB 디버깅] 활성화
1. 다시 **[설정]**의 맨 아래로 가면 새로 생긴 **[개발자 옵션]** 메뉴로 들어감
2. **[USB 디버깅]** 스위치를 **[켬]**으로 활성화

### 3단계: 스마트폰과 PC를 USB 케이블로 연결
1. USB 케이블로 PC와 스마트폰 연결
2. 스마트폰 화면에 **"USB 디버깅을 허용하시겠습니까?"** 팝업이 뜨면:
   - **[이 컴퓨터에서 항상 허용]** 체크
   - **[허용]** 버튼 터치

### 4단계: 원클릭 설치 및 실행
프로젝트 폴더의 **`install_to_phone.bat`** 파일을 더블 클릭하면 자동으로 연결을 확인하고 기기에 앱을 설치한 후 스마트폰에서 즉시 실행합니다!

또는 터미널(PowerShell)에서 아래 명령어를 직접 실행해도 됩니다:
```powershell
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

### 5단계: 앱 권한 허용 및 드럼 튜닝
1. 앱이 실행되면 **오디오 녹음(마이크) 권한**을 **[앱 사용 중에만 허용]**으로 승인합니다.
2. 스마트폰을 드럼 림 근처(러그에서 약 3~5cm 떨어진 위치)에 놓고 스틱으로 가볍게 러그 근처를 타격하면 실시간으로 정밀 측정됩니다!
